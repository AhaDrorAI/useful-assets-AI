# Tipster PRD

## Problem
Splitting a restaurant bill with tip is fiddly on a phone.

## Users
Friends at a restaurant, one phone.

## First version
- One screen: bill amount, tip % (10/12/15/custom), number of people.
- Shows total and per-person amount, rounded to 0.5 ILS.
- Works offline as a PWA.

## Out of scope
Accounts, history, currency conversion.

## Success
A user gets the per-person amount in under 10 seconds.
