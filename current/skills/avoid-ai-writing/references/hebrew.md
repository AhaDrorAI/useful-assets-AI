# Hebrew module — avoid-ai-writing

Load this file **in addition to** SKILL.md whenever the audited text is in Hebrew.
SKILL.md stays authoritative for method, modes, severity tiers and output format. This file replaces only the pattern lists, because those lists are English and do not fire on Hebrew.

## Why a separate module

Hebrew LLM output is, in practice, English output that was translated. So two different things go wrong at once:

1. **Carryover.** Every AI-ism in the English table lands in Hebrew as a calque. Same tell, different letters.
2. **Hebrew-only failure.** Translation pushes the register up. Models default to formal, written, quasi-legal Hebrew, plus gender and typography errors that do not exist in English at all.

Audit for both. Layer 1 alone leaves text that is clean of clichés and still reads like a translated contract.

## Register profiles (Hebrew)

Same idea as the English profiles, different calibration.

| Profile | What it means |
|---|---|
| `linkedin-he` | Israeli professional social. Short. Direct. First person. Contractions of speech are fine. This is the default for Dror's Hebrew. |
| `dm-he` | One to one message to an Israeli. The strictest. Any formality reads as a template. |
| `marketing-he` | Landing pages, ads. Watch promotional inflation hardest. |
| `formal-he` | Official letter, government form, academic. Here `אשר` and `על מנת` are allowed. This is the only profile where layer 2.1 relaxes. |

If no profile is given and the text is Hebrew, assume `linkedin-he`.

## 1.3 Idiom calques (Hebrew-specific evidence)

These are documented Hebrew AI tells, not theory.

- `בהיר כקריסטל` (crystal clear). לא ביטוי עברי. השתמש ב"ברור".
- `כאן נכנס לתמונה X` (this is where X comes in). תבנית מעבר של מודל.
- `משנה את כללי המשחק`.
- `לשים את הדברים על השולחן`, `ללכת עם זה`. סלנג שנשתל כדי להישמע אנושי. ראה 3.2.

## 1.4 Structural patterns

Everything in SKILL.md about sentence shape applies unchanged, because rhythm is language independent.

- **חוק השלושה.** שלושה פריטים מקבילים, שוב ושוב. שנה למספרים אחרים.
- **אורך משפט אחיד.** בעברית זה בולט אפילו יותר, כי עברית דחוסה יותר מאנגלית ומשפט של 25 מילים כבר ארוך מאוד.
- **אורך פסקה אחיד.**
- **סבב מילים נרדפות.** מודל יסובב "עובדים, מועסקים, אנשי הצוות, כוח האדם" בפסקה אחת. אדם חוזר על המילה הנכונה.
- **חזרה כפייתית על מונח המפתח.** הצד השני של אותו מטבע, ותועד כסימן מסגיר בעברית.
- **משפטים מעגליים.** "שיווק מבוסס נתונים מתחיל באיסוף נתונים". נכון, ריק, ומסגיר.

# Layer 2 — Hebrew-only tells

## 2.1 אינפלציית רגיסטר (the big one)

תרגום מכונה מעלה את המשלב. זו התקלה הכי שכיחה ובעברית היא מסגירה יותר מכל מילת באזז.

| מסגיר | טבעי |
|---|---|
| מהווה | הוא, היא, זה |
| ניתן ל | אפשר ל |
| נדרש | צריך |
| מתבצע / מבוצע | קורה, עושים |
| אשר | ש |
| הינו / הינה | הוא, היא, או למחוק לגמרי |
| על מנת | כדי |
| בכדי | כדי (וגם שגוי) |
| במידה ו | אם |
| מן | מ |
| בטרם | לפני |
| כלל וכלל | בכלל |
| טרם | עוד לא |
| לאור העובדה ש | כי |
| במסגרת | ב, או למחוק |
| בעל אופי X | X |
| מבחינת / בהיבט של | (לנסח מחדש) |

`מהווה` הוא המקבילה המדויקת של copula avoidance באנגלית (serves as, represents). זו הבדיקה הכי מהירה: חפש "מהווה", "ניתן", "אשר", "הינו", "על מנת". ארבעה מתוך חמישה בטקסט קצר, וכמעט בוודאות זה תרגום.

Exception: profile `formal-he`.

## 2.2 תבניות ניגוד

התבנית החתומה של מודלים בעברית.

- `לא רק X, אלא גם Y` — התבנית המתועדת ביותר. מקסימום אפס בטקסט קצר.
- `זו לא X, זו Y` / `לא X, אלא Y` — אותה חיה בגרסה קצרה.
- `...ולא Y` בזנב משפט (למשל "זו תשובה לגיטימית ולא כישלון") — הגרסה החלשה, ועדיין מסגירה.
- `זה לא עניין של X, זה עניין של Y`.

התיקון תמיד זהה: לומר את הצד החיובי ישירות ולמחוק את הצד השלול.

## 2.3 מין ומספר

- **ברירת מחדל זכר יחיד לאורך כל הטקסט.** "עליך להירשם", "כעת אתה יכול". מסגיר בעברית, ולעיתים גם לא נכון לקהל.
- **אי התאמה בין נושא לנשוא** במין או במספר, בעיקר במשפטים ארוכים. בדוק ידנית.
- **פנייה שמחליפה גוף באמצע הטקסט**, מ"אתם" ל"אתה" ל"המשתמש".

## 2.4 תחביר מתורגם

- **שרשראות סמיכות וסמיכות של "של".** "המטרה של השיפור של התהליך של הצוות". לפרק למשפטים.
- **כינוי מוסב מיותר.** "האיש שראיתי אותו" במקום "האיש שראיתי".
- **סדר מילים אנגלי.** תואר לפני שם עצם, נושא תמיד ראשון, אפס היפוך.
- **סביל חסר שחקן.** "הוחלט", "בוצע", "נמצא כי". מי החליט.
- **"זה ש" כפתיח משפט** במקום שם פועל.
- **שם פעולה במקום פועל.** "ביצענו בדיקה של" במקום "בדקנו". זהה ל nominalisation באנגלית.

## 2.5 טיפוגרפיה ופיסוק

זו הבדיקה הכי מהירה בכל הקובץ ואפשר לעשות אותה במכונה.

- **מקף ארוך (—) ומקף בינוני (–).** אסורים. גם בעברית. החלף בנקודה, פסיק או סוגריים.
- **מקף עליון / מקף גבוה.** וריאנט פחות מוכר שמודלים מייצרים. אסור.
- **מרכאות מסולסלות (" " „ ").** מודלים מייצרים מרכאות פותחות בתחתית השורה. בעברית תקנית משתמשים במרכאות כפולות ישרות.
- **מקף מחבר בין אות עברית לאנגלית, בלי רווחים.** `ב-SAP`, `מ-1984`, `ל-API`.
- **גרש וגרשיים** לפי כללי האקדמיה. `ק״ג`, `ד״ר`, `צה״ל`.
- **ספרות מערביות**, עם פסיק מעל 999: `1,000`.
- **טווחים נכתבים מימין לשמאל:** `40–60 ק״ג`, `20%–30%`.
- **אמוג'י בכותרות.** אסור. בסוף שורה בפוסט, אחד או שניים, מותר.

## 2.6 מונחים לועזיים

- אל תתרגם שמות מוצר. "אמצע מסע" במקום Midjourney הוא הכישלון הקלאסי.
- בחר עמדה אחת לכל טקסט: `אפליקציה` או `app`, `מודל שפה` או `LLM`. אל תסובב ביניהם.
- ראשי תיבות באנגלית נשארים באנגלית, עם הסבר בעברית בהופעה ראשונה אם צריך.

# Layer 3 — מה לא לעשות

## 3.1 אל תזריק סלנג

הכשל הנגדי, והוא נפוץ אצל מי שמנסה "להאניש" עברית. "יאללה", "סבבה", "אחלה", "בוא נשים את זה על השולחן" בטקסט מקצועי נשמעים כמו מודל שקיבל הוראה להישמע ישראלי. סלנג נכנס רק אם זה באמת קול הכותב, ואז הוא נכנס בכמות שהוא נכנס בדיבור, כלומר מעט.

הבדיקה: האם המילה הזאת הייתה יוצאת מהפה של הכותב בפגישה? אם לא, החוצה.

## 3.2 אל תסנן יתר על המידה

עברית טבעית כוללת אי סדר. משפט קטוע, משפט שמתחיל ב"אבל", סוגריים באמצע רעיון. ליטוש מלא מחזיר את הטקסט בדיוק לפרופיל שמנסים לברוח ממנו.

## 3.3 אל תמחק מונח מקצועי כי הוא ברשימה

אם `מודל`, `תהליך` או `מערכת` הן המילים הנכונות, הן נשארות, גם שלוש פעמים בפסקה.

# בדיקה מהירה (30 שניות)

לפי סדר תשואה יורדת:

1. חפש `—`, `–`, מרכאות מסולסלות. מחק.
2. חפש `מהווה`, `ניתן`, `אשר`, `הינו`, `על מנת`, `במידה ו`. החלף.
3. חפש `לא רק ... אלא גם`, `זו לא ... זו`, `ולא` בזנב משפט. נסח מחדש כמשפט חיובי.
4. חפש פתיחים: `בעידן`, `בעולם של היום`, `חשוב לציין`, `אין ספק`, `בואו נעשה סדר`. מחק.
5. קרא בקול. אם כל המשפטים באותו אורך, שבור אחד לשניים ואחד לחצי.
6. בדוק התאמת מין ומספר, ואת הגוף שאליו פונים.

אם עוברים על 3 קטגוריות ומעלה, אל תטליא. כתוב מחדש מהמשפט המרכזי.

# מקורות

הרשימות בקובץ הזה נשענות על:

- Gengo Hebrew translator style guide. המקור לטבלת אינפלציית הרגיסטר (כדי / על מנת, אם / במידה ו, הוא / מהווה, ש / אשר, מ / מן), לכללי הפיסוק, לגרשיים, לספרות ולטווחים.
- טל אייזנמן, "שלושת הסימנים הכי מסגירים". המקור למקף הארוך, למקף העליון, למרכאות המסולסלות, לתבנית "לא רק אלא גם" ולקאלקים "בהיר כקריסטל", "משנה את כללי המשחק", "כאן נכנס לתמונה".
- The Shark Lady, זיהוי טקסט שנכתב בבינה מלאכותית. המקור לברירת המחדל של זכר יחיד, לחזרה על מונח המפתח, למשפטים המעגליים ולתרגום שמות מוצר.
- נועה סיסטם, איך לגרום ל-AI להישמע אנושי בעברית. המקור לרשימת הפתיחים (בעידן המודרני, חשוב לציין, אין ספק, ראוי לזכור) ולאזהרה על הזרקת סלנג.
- Hack23 Hebrew translation guide. RTL, שמות מותג שלא מתרגמים, ותרגומית.
- SKILL.md של avoid-ai-writing. כל שכבת המבנה והקצב, ללא שינוי.
