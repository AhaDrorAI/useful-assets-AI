# Forbidden patterns

Copy this file next to the writing it governs, drop the `.template` from the name,
and tell the agent to check every draft against both this file and the
`avoid-ai-writing` skill.

Add one line each time a tell gets past you. Keep the fix beside the pattern: a
list of banned phrases without replacements produces stilted avoidance rather
than better writing. Delete lines that stop earning their place.

This file beats the general skill on your own recurring problems, because it is
allowed to encode house style that would be wrong to impose on everyone.

## Patterns

| Pattern | Example | Fix |
|---|---|---|
| Negated setup | "That's not compliance. That's stalling." | Keep the second half only. "They're stalling." |
| Paired fragments | "Fast. Simple." | Keep one, or write the full sentence. |
| Two-image contrast | "Less a hammer, more a scalpel." | Say the action instead. |
| Self-applause tag | "And that matters." | Delete. The paragraph loses nothing. |
| X-of-Y analogy | "The Excel of AI agents." | Say what it does. |
| Warm-up phrase | "Here's the thing." | Start one sentence later. |
| Forced triad | "Faster, cheaper, smarter." | Use the number of reasons you actually have. |
| Hedged range | "5 to 10 minutes." | Give the measured number. "7 minutes." |
| Recap ending | "In short…" | Stop typing. |
