# Deliverable Templates

Output structures for the Execute phase. Adapt tone and language to the user (respond in their language); keep the structure. Always fill templates with the user's actual product, ICP, and voice — never generic placeholders.

## 1. 30-Day Traction Plan

Use when the user wants an actionable roadmap for their chosen channel(s).

```
# 30-Day Traction Plan: [Product]
**Channels:** [1-2 chosen channels] | **Goal:** [one concrete metric, e.g., 200 waitlist signups / 10 demo calls]
**Weekly time budget:** [from diagnosis]

## Week 1: [theme]
- [ ] Specific action (with day, time estimate)
- [ ] ...
## Week 2-4: [same structure]

## What to measure
- Primary: [conversion metric — signups/demos/activation]
- Secondary: [leading indicators]
- Explicitly NOT tracking: [vanity metrics to ignore]

## Expectations
[Honest time-to-results for these channels; what "working" looks like at day 30 vs. what requires 90 days]
```

## 2. LinkedIn / Founder Content Calendar

Use for founder-led content channels. Produce actual draft posts, not just topics.

```
# Content Calendar: Weeks 1-2
**Cadence:** [3-4/week] | **Narrative arc:** [the ongoing story, e.g., "building X in public while learning Y"]

## Post 1 — [day] — [format: text/carousel/video]
**Hook:** [first line — must work standalone in the feed]
**Draft:** [full post text in the founder's voice]
**CTA:** [what the reader should do]

[repeat per post; mix: journey/lesson posts, actionable value posts, engagement/question posts]
```

## 3. Lead Magnet Spec

```
# Lead Magnet: [working title]
**Painful problem it solves:** [specific, for the exact ICP]
**Format:** [playbook / template / database / original research / tool]
**Why they'd trade an email for it:** [the value test]
**Outline:** [sections]
**Distribution plan:** [which channels push it — a magnet with no distribution is a PDF in a drawer]
**Landing page copy:** [headline + 3 bullets + CTA]
```

## 4. Launch Checklist

Condense from pre-launch.md phases into a dated checklist for the user's actual launch date, working backward from Day 0.

## 5. Cold Outreach Drafts (signal-based)

```
# Outreach Kit: [signal type, e.g., "companies that just posted a job for X"]
**Where to find the signal:** [specific sources]
**Message draft (<100 words):**
[Name the signal → connect to pain → specific value → soft CTA]
**Follow-up (day +4):** [draft]
**Daily volume:** 10-20 personalized, not 500 templated
```

## 6. GEO Content Brief

Use with geo-aeo.md when creating AI-citable content.

```
# GEO Brief: [target buying question]
**Fan-out sub-queries to cover:** [3-5 shorter queries the AI will actually search]
**Page type:** [comparison/listicle/FAQ/answer page]
**Extraction elements to include:** [specific statistics, expert quote, FAQ block, schema type]
**Sources currently cited by AI for this question:** [check Perplexity/ChatGPT — where else should the brand appear?]
**Freshness plan:** [what gets updated quarterly]
```
